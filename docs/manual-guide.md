# 사람이 할 일 안내 (2026-10-08 갱신, 제출 10/12)

**공통 원칙**
- 제조사(AMD·인텔·NVIDIA) **공식 페이지**를 직접 열어 확인한다. 다나와·리뷰 사이트·다른 AI의 답은 근거로 쓰지 않는다.
- 값을 본 페이지 주소를 함께 보낸다. 주소가 없으면 `verified=false`로 들어간다.
- **시트를 직접 고치지 않아도 된다.** 채팅으로 아래 형식대로 보내면 Claude가 넣고 `run_all`을 다시 돌린다.
- 모르면 비워 둔다. 빈칸은 "확인 필요(UNKNOWN)"로 남는다.

## 1·3. `chipset_support_by_uarch.csv`: 인텔 칩셋 지원

**질문:** "이 세대 CPU를 이 칩셋 보드에 꽂을 수 있나?"

**하는 법**
1. 검색창에 `Intel Z890 chipset` 처럼 칩셋 이름을 넣고 **intel.com 또는 intel.co.kr** 결과만 연다(제품 사양 페이지, 주소에 `/products/sku/`가 들어감).
2. 페이지에서 **"호환 제품"(Compatible Products)** 또는 **"지원 프로세서"** 부분을 찾는다. 이 칩셋과 함께 쓰는 CPU 세대가 나열돼 있다.
3. 세대마다 셋 중 하나로 판단한다.
   - `S` (SUPPORTED): 목록에 있음
   - `B` (BIOS_REQUIRED): 목록에 있지만 BIOS 업데이트가 필요하다고 적혀 있음
   - `U` (UNSUPPORTED): 목록에 없음이 분명함
   - `?`: 페이지에서 판단이 안 됨 → 빈칸으로 둔다

**칩셋 페이지 한 개로 채워지는 줄**

| 순서 | 칩셋 | 물어볼 세대 |
|---|---|---|
| 1 | Z890, B860, H810, Q870, W880 | Ultra 200S(Arrow Lake), Ultra 200S Refresh(Arrow Lake Refresh) |
| 3 | B760, H770, Z790, W680 | 12세대(Alder Lake, B760·H770·Z790·W680만), 13세대(Raptor Lake), 14세대(Raptor Lake Refresh) |
| 3 | B660, H610, H670, Q670, Z690 | 13세대, 14세대 (12세대는 오늘 입력함) |

**보내는 형식** (한 줄에 칩셋 하나)
```
Z890: 200S S / Refresh S / https://www.intel.co.kr/...
B760: 12세대 S / 13세대 S / 14세대 S / https://www.intel.co.kr/...
B660: 13세대 B / 14세대 B / https://www.intel.co.kr/...
```
오늘 넣은 12세대 5줄(B660·H610·H670·Q670·Z690)도 그때 본 페이지 주소를 한 줄로 보내면 `verified=true`로 바꾼다.

## 2·7. `verification_sample.csv`: 검증 표본 60건

**무엇을 하나:** 데이터셋에 들어간 값 60개를 공식 페이지 값과 비교한다. 등급(위키 각주 있음/없음 등)마다 정확도를 내는 데 쓴다.

**줄마다 보는 칸:** `model_name`(모델), `field`(항목), `value`(우리 값). `source_url`·`source_tier`는 건드리지 않는다.

**판정 규칙**

| 항목 | 공식 페이지에서 볼 곳 | 일치 기준 |
|---|---|---|
| `release_date` | 인텔 ARK "출시일", AMD "출시일" | 같은 분기면 일치(ARK는 `Q4'21`처럼 분기만 나옴) |
| `msrp_usd` | 인텔 "권장 고객 가격", AMD·NVIDIA 출시 보도자료 | 같은 금액이면 일치. 인텔이 범위(예: $589–$599)로 주면 범위 안이면 일치 |
| `cores`·`threads`·`boost_clock_mhz`·`tdp_w`·`l3_cache_mb`·`shader_count` | 사양 표 | 같은 숫자면 일치. 단위만 다르면 일치(5.0GHz = 5000MHz) |

- 공식 페이지에 그 값이 아예 없으면 `na`로 보낸다. 정확도 계산에서 빠지고 "공식 값 없음" 건수로 따로 보고한다.

**보내는 형식** (`행 번호`는 CSV의 줄 순서, 머리줄 제외 1부터)
```
1. 일치 / https://www.amd.com/...
2. 불일치: 2026-07-29 / https://...
5. na
```
Claude가 `match`(true/false/na), `official_value`, `official_url`, `checked_at`을 채우고 `checked_by`는 가명 `R1`로 넣는다(실명 비공개).

**재판정(생략, 2026-10-09 사용자 결정):** 첫 판정 48시간 뒤, Claude가 무작위로 고른 12건을 **이전 답을 보지 않고** 다시 판정한다. 두 번의 판정이 얼마나 같은지(자기 일치도)를 논문에 쓴다. 10/9에 끝내야 10/11에 재판정할 수 있다.

## 5. `family_facts.csv`: 세대 정보 확인 (13줄)

이미 공식 확인된 것: Ryzen 7000, Ryzen 9000, Core Ultra 200S Refresh. 나머지는 AI가 만든 보고서 값이라 미확인 상태다.

| CPU 세대 | 대표 모델(이 모델 페이지 하나만 보면 됨) |
|---|---|
| Ryzen 5000 | Ryzen 7 5800X |
| Ryzen 5000G | Ryzen 7 5700G |
| Ryzen 8000G | Ryzen 7 8700G |
| Core 11세대 | Core i7-11700K |
| Core 12세대 | Core i7-12700K |
| Core 13세대 | Core i7-13700K |
| Core 14세대 | Core i7-14700K |
| Core Ultra 200S | Core Ultra 7 265K |

확인할 값: 소켓, 메모리 종류(DDR4/DDR5), 최대 메모리 크기.

칩셋 계열 5줄(AM4·AM5·LGA1200·LGA1700·LGA1851)은 소켓 이름과 메모리 세대만 확인한다. 위 칩셋 지원 작업 때 본 칩셋 페이지로 같이 확인할 수 있다.

**보내는 형식**
```
Ryzen 5000: 맞음 / 128GB / https://www.amd.com/...
Core 12세대: 맞음 / 128GB / https://www.intel.co.kr/...
LGA1700: 맞음 / https://www.intel.co.kr/...
```
"맞음"은 지금 들어 있는 소켓·메모리 세대가 공식 값과 같다는 뜻이다. 다르면 "다름: DDR5만"처럼 적는다.
